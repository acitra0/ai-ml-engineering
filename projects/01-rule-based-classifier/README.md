## Rule-Based vs. Supervised Machine Learning
1. Our current classifier works by categorizing customers into either VIP, At Risk, or Regular.  They are categorized as VIP if they have spent more than $1000, have more than 10 orders, and have purchased in the last 30 days. They are categorized at risk if it has been more than 90 days since their last purchase. Everyone else is categorized as a regular.

We would build a supervised ML version by obtaining data, formatting it into a tabular format with target labels, training the model with the formatted data, maybe testing multiple models, then test the models against the validation dataset, pick the best model, and then test it against the test dataset.
